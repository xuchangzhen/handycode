# 菜鸟包裹：官方 API 与 H5 可行性调查

调查日期：2026-11-18。此报告区分公开文档、现场观察与尚未取得的授权；不含手机号、运单号、Cookie、密钥或订单内容。

## 结论和实际证据

现阶段采用方案 C：不接入 TOP 签名 API；提供用户主动打开的菜鸟官方网页与官方 App 入口。**没有实现菜鸟包裹自动同步**。API 应用权限、本人手机号调用及完整覆盖均未经验证，不能将公开文档当成调用成功。

- 公开文档可见。查询接口的示例调用使用 AppKey 和 AppSecret。文档标签“不需要授权”只表示公共 `session` 参数在该标签下不需要，并不证明应用具备 API 权限或可以任意处理用户资料。[TOP API 接入说明](https://developer.alibaba.com/docs/doc.htm?articleId=122468&docType=1&treeId=846) 区分 AppKey、AppSecret、Session、API 管理与审核；该文是飞猪分销场景的示例，不能代替这三个 API 的专属准入规则。
- [TOP 常见问题](https://developer.alibaba.com/docs/doc.htm?articleId=101163&docType=1&treeId=1) 说明个人可以按规则注册开发者，具体 API 权限受应用标签等限制；其服务市场语境还列出抓取页面数据属于禁止接入的应用类型。该条是否适用于此独立开源项目及此 H5 页面尚未获官方确认，不能将其扩大解释为所有个人网页浏览均被禁止，也不能假定本项目的数据提取已经获准。
- 开发者控制台跳转 `login.taobao.com` 时浏览器站点安全策略拒绝访问；没有查看用户的控制台、申请权限、输入账号密钥或调用受保护接口。是否存在已创建应用、可申请的具体应用类型、权限包、个人资质、本人手机号范围和审核结论均**未知**。用户可通过自行正常访问控制台或联系平台核验，勿向本项目提交密钥。
- 普通 Android WebView 访问[菜鸟官方“我的快递”页面](https://page.cainiao.com/guoguo/app-myexpress-taobao/)时，真机现有登录会话在一个只读检查中显示 5 条待收记录；其中 5 条有可解析运单号和承运商，3 条有非默认状态文字。没有记录包裹字段本身。独立菜鸟 App 首页显示“查收 27”，但网页首屏、分页和 App 数字可能口径不同，不能算作逐条对照，也不能推断网页完整覆盖；网页已收、取件码、历史及顺丰覆盖尚未验证。
- 同一真机会话测试禁用第三方 Cookie 后未读到可识别列表；允许第三方 Cookie 的一次检查可显示 5 条。该观察不足以证明因果或将来稳定性，但说明不能假定禁用后仍可用。查看入口沿用该登录方式，限制请求到菜鸟、淘宝、天猫、支付宝、阿里巴巴及阿里 CDN 的 HTTPS 域名；WebView 可能向这些官方服务发送各自适用的 Cookie。本应用不读取或另存 Cookie，也不引入开发者中转服务。
- H5 模板把缺失状态默认显示为“运输中”，不能把这个默认文字当成真实物流节点。基于授权边界和覆盖不确定性，本次不将页面 DOM 或页面内部接口导入聚合缓存，不触发页面的删除功能。

签名接口在当前无可信服务端架构下，不能把长期 AppSecret 编进公开 APK，也没有查到针对这几项接口可替代长期共享密钥且适用于本项目的纯客户端签名方案。因此当前不实施 API 接入；这不等于断言平台一定要求所有架构必须建自有服务器。

## 其他产品边界

- [菜鸟裹裹商家寄件取号 API](https://open.fliggy.com/docs/api.htm?apiId=66813) 是商家寄件，不是消费者自动聚合查询。
- [自提柜订单包裹 API](https://doc.alidayu.com/docs/api.htm?apiId=28357) 面向自提柜订单，不能等同全网收寄件。
- [菜鸟官网产品说明](https://page.cainiao.com/mcn/actpc/cnindexpc.html)描述的是菜鸟 App 的产品能力，并非第三方开放 API 权限；[菜鸟隐私说明](https://page.cainiao.com/guoguo/guoguo-privacy/20180125.html)描述其自有服务的数据授权和聚合方式，也不授予 HandyCode 这些 API 权限。
- 尚未找到经官方文档证实、可由无中转服务器的个人第三方应用安全调用、按本人绑定手机号发现全部收寄件并覆盖菜鸟 App 的接口。菜鸟速递承运商接口、商家物流、自提柜及个人聚合产品不能互相等同。

## 继续验证的条件

取得平台对应用类型、API 权限、合法用户授权、可用的安全签名架构和网页数据提取的明确答复后，再在本人账号上比较分页、状态、取件码和已知非电商件；需要验证增量同步、脱敏、失败保留、去重和本地加密。验证前保留菜鸟 App 降级入口，不能把页面空白或有限列表解释成“没有包裹”。
