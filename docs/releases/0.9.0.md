# HandyCode 0.9.0

这是基于 HandyCode 的个人维护版本，包含包裹总览和应用内检查更新。身份码仍使用各平台官方网页；原有四平台标签、小号手机号绑定和逐平台退出入口保留。

## 安装前请注意

此版本使用新的个人签名，**不能直接覆盖原作者签名的旧版**。Android 会拒绝覆盖安装；如果自行卸载旧版，原版的本地登录会话和数据会被删除，需要重新登录。请先确认自己能重新登录各平台。此后由相同个人密钥签名的后续版本可直接覆盖更新。

## 更新功能

打开应用顶部“包裹”→“检查应用更新”。应用访问本项目 GitHub Release；发现新版本后由用户选择下载，下载完成后核对 SHA-256、包名、版本号和签名，再由 Android 系统显示安装确认界面。Android 可能要求先允许 HandyCode 安装来自此来源的应用；应用不会静默安装。首次从旧版切换仍需自行下载本 APK，旧版并不具备此更新入口。

## 物流能力与限制

- 京东现有官方订单页数据可在总览中查看并加密缓存；支持手动刷新、可选择的启动/周期同步和到件通知。
- 淘宝、拼多多官方页面中，明确返回待取状态、运单号和取件码的记录可纳入缓存；未识别稳定标识的待取码只是临时预览，可能重复。
- 多平台完整订单同步、完整物流轨迹、菜鸟独立同步和各平台后台同步尚未完成；小号能看到的数据范围以官方页面实际返回为准。
- 上述真实平台数据接入、身份码和登录会话未在真实账号和真机上重新验收。不要把总览数据不完整理解成没有包裹。

## 隐私与权限

物流缓存只存本机，使用 Android Keystore 加密，可在总览中清除且不注销账号。应用不上传 Cookie、验证码或身份码，不接入统计服务。通知在用户主动开启时申请；后台网络使用系统调度，默认关闭。检查更新时会连接 GitHub。新增安装应用权限仅用于交给系统安装用户选择的更新。
