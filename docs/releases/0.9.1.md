# 驿拾包裹 0.9.1

原个人维护版 HandyCode 现改名为 **驿拾包裹**。“驿”对应驿站与物流，“拾”寓意收取与汇集包裹。

- 桌面和系统安装界面显示新名称；原有四平台身份码、包裹总览、登录方式与操作保留。
- 本版与个人签名的 0.9.0 使用相同包名和证书，可通过“包裹 → 检查应用更新”下载，由系统确认后覆盖安装，无需卸载；覆盖更新不主动清除登录会话。
- 为兼容已发布的 0.9.0，GitHub 仓库和 APK 文件仍沿用原技术地址与文件名。项目基于 HandyCode，保留原 MIT 许可证及第三方声明。
- 本版仅调整名称，物流功能仍有未完成项：部分平台和账号的完整订单、完整轨迹及真实设备验收尚未完成；数据缺失不代表没有包裹。详见功能差异记录。

**从原作者签名的版本切换：** 个人版仍无法直接覆盖原作者签名的安装包。卸载旧版会删除其本地登录状态和数据，请先确保可以重新登录。
