## 基线与约束

执行 `npm ci --ignore-scripts` 前，20 个 JS 测试中 12 个因缺失 linkedom 无法运行；安装项目锁定的开发依赖后 20/20 通过。构建脚本列出的七组纯 Java 测试全部通过。原脚本依赖 Windows 可执行文件和 PowerShell，macOS 上 `pwsh` 不存在；原 Release 签名密钥未提供，不得另签后宣称可覆盖原版。Android SDK 要求 platform 35、build-tools 36.0.0。没有已连接设备。

## 分阶段验收

A 基线与差异；B 模型、去重、缓存和虚构数据测试；C 平台接入按 PDD、淘宝/菜鸟、京东逐项验证，无法可靠读取时保持未支持；D 局部总览及详情；E 可授权的后台与提醒；F 真机回归身份码、会话、真实订单及网络异常。缺少账号和设备时不得把模拟测试当作真机验收。最终实施状态详见本文件末尾。

## 本次实施结果（2026-11-17，继续实施后）

- 已完成：保守的身份和状态模型、拆包与多订单引用测试、显式承运商和运单一致时的跨平台合并规则；独立加密缓存、筛选、详情、复制与清除；京东订单页的前台手动读取，及仅在响应明确提供字段时提取运单、承运商和轨迹并排序。此字段映射通过虚构数据测试，真实京东订单是否返回对应结构尚未验证。
- 部分完成：淘宝/拼多多当前已打开页面在官方响应同时明确给出待取状态、运单号和取件码时导入加密缓存；其他待取码作为只在当前界面内的临时预览，不读取身份码或表单。仅凭取件码不合并，预览可能重复且空预览不表示没有包裹；上述响应字段映射仅用虚构数据测试，真实页面尚待验证。京东数据可能不完整，未再次出现的旧记录保留并标记历史缓存；其现有订单脚本过滤取消/退款，旧记录不会因此自动更新。无运单号的拆包不能可靠区分，切换账号前应按需清除旧缓存。
- 京东后台：可分别选择启动时一次同步和约 6 小时的周期任务，默认均关闭，受网络、电量和系统调度约束，时间不精确；启动任务与前台京东页、周期任务之间有避让。使用单独 WebView 和系统 Cookie 存储，不导出 Cookie、不提交登录或验证。进程重启后恢复周期安排，设备重启后的周期安排需下次打开应用恢复。支持可选到件通知：各平台首次识别基线静默，仅对之后已识别的新待取变化发通用提示，默认关闭；Android 13+ 在用户主动开启时请求权限。
- 尚未实现：淘宝/天猫、拼多多及菜鸟的完整订单同步、独立后台任务和真实页面字段适配；真实平台的完整轨迹抓取、图片和驿站字段；可靠的无运单拆包、全部历史归档、跨平台真实数据验证、多平台失败隔离管理、网络增量请求优化。原平台官方页面与 PDD 小号手机号验证继续保留；小号可见范围必须实测。
- 限制原因：现有 PDD/淘宝页面主要为 DOM 投影，缺少已验证的稳定订单/运单映射；未登录、无真实订单或轨迹样本时，无法确定官方页面结构和账号权限。没有绕过验证码、复制 Cookie、访问官方 App 私有数据、创建服务器或虚构物流节点。

## 验证与交付

- `npm ci --ignore-scripts` 后，`node --test tests/*.test.mjs` 的 22 个测试文件通过，覆盖投影来源和身份区隔离、快递状态、真实格式时间排序、显式即时配送过滤等；原有七组 Java 测试与新增模型测试通过。当前测试不等同于真实平台接口验证。
- Windows 原构建脚本 `pwsh -File ./build-android.ps1 -Configuration Release` 因本机没有 PowerShell 不能执行，原 Release 签名密钥未提供。先对基线源码执行了同 SDK 工具链的 macOS 测试构建；当前使用 `./tools/build-android-macos-test.sh`。此辅助入口使用 `.local/macos-test-only.keystore`，测试 APK 不能覆盖官方签名版本，也不是正式 Release。
- Android 36 模拟器、虚构数据：加密缓存重读、官方响应的虚构待取数据导入及清除后防重复写回、状态变化、通知不含敏感字段、任务启停、启动任务安排、清除缓存与 Cookie 隔离通过；强制运行周期任务时无账号，得到“京东需要登录或会话已失效”，未尝试自动登录。总览筛选经过 UI 检查。真实账号、页面字段和真机身份码尚未验证。
- Manifest：`debuggable=false`、`allowBackup=false`、`usesCleartextTraffic=false`；新增 `ACCESS_NETWORK_STATE` 供系统网络约束及用户可选的 `POST_NOTIFICATIONS`。WebView 调试随 debuggable 关闭。未新增第三方域名、统计、云服务或 Cookie 导出；静态检查不替代真机网络流量核验。
- HandyCode MIT 与仓库内 AndroidX WebKit Apache-2.0 许可声明保留。参考工程为 GPL-3.0，未直接复制其代码；工程记录不构成法律意见。

真机验收：使用独立测试设备，勿为安装不同签名的测试包卸载现有正式版；登录各平台官方页面，核验身份码、刷新、旋转、亮度、手势、主题、退出和 PDD 小号手机号验证。比较真实订单页面与总览；验证轨迹字段、拆包、到件通知、启动/后台同步及登录过期提示。离线与重启后检查旧缓存和时间，清除缓存后确认会话仍在。未完成的平台订单同步及完整轨迹无法验收。
