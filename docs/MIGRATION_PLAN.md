## 基线与约束

执行 `npm ci --ignore-scripts` 前，20 个 JS 测试中 12 个因缺失 linkedom 无法运行；安装项目锁定的开发依赖后 20/20 通过。构建脚本列出的七组纯 Java 测试全部通过。原脚本依赖 Windows 可执行文件和 PowerShell，macOS 上 `pwsh` 不存在；原 Release 签名密钥未提供，不得另签后宣称可覆盖原版。Android SDK 要求 platform 35、build-tools 36.0.0。没有已连接设备。

## 分阶段验收

A 基线与差异；B 模型、去重、缓存和虚构数据测试；C 平台接入按 PDD、淘宝/菜鸟、京东逐项验证，无法可靠读取时保持未支持；D 局部总览及详情；E 可授权的后台与提醒；F 真机回归身份码、会话、真实订单及网络异常。缺少账号和设备时不得把模拟测试当作真机验收。最终实施状态详见本文件末尾。

## 本次实施结果（2026-11-17）

- 已完成：独立状态与身份模型、保守排序和去重；京东既有官方订单页快照在页面成功读取后增量写入本机缓存；入口、筛选、简要详情和复制取件码；Keystore AES-GCM 加密、原子写入、备份关闭及不触及 WebView 的缓存清除；对显式即时配送标签进行过滤。测试数据均为虚构。缓存失败显示提示，不输出业务敏感数据；解密失败不会自动覆盖原文件。
- 部分完成：京东只读取现有页面捕获的订单列表，页面和登录可能限制范围，订单没有运单号时只是暂定订单记录；无法可靠区分同订单拆包，不支持跨平台自动合并；在列表中未再出现的旧记录保留并标示为历史缓存，不自动推断签收或删除。京东现有脚本过滤取消/退款，旧记录不会因此自动更新；同一账号切换后旧缓存不会自动区分账号。请在切换京东账号前按需清除缓存。
- 尚未实现：PDD、淘宝/天猫、菜鸟的总览数据接入和独立同步；真实运单号、快递公司、图片、驿站和完整物流轨迹；实际轨迹解析及时间排序；订单详情跟踪、真正的历史归档和跨平台合并；多平台失败隔离的同步管理器、启动同步配置、后台同步、通知和增量请求优化。原来的淘宝和拼多多官方待取页面、手机号验证与官方运单查询入口继续保留，但不能据此声称小号能看到主账号全部订单。没有为同步创建后台服务、代理或读取 Cookie。
- 原因：现有 PDD/淘宝页面是官方 DOM 投影，未提供经过验证的稳定订单/运单标识映射；未登录、无真实订单或轨迹样本时，无法验证官方响应的语义、拆包和状态归属。京东现有捕获代码仅有简化订单字段。为避免把取件码、DOM 文本或订单号伪装成真实运单，未猜测这些字段或构造节点。后续须以用户主动登录的官方页面、脱敏的虚构化结构样本和真机验证逐项补齐。

## 验证与交付

- `npm ci --ignore-scripts`；`node --test tests/*.test.mjs`：20/20 测试文件通过。项目原有七组 Java 测试与新增状态/去重测试通过；`tools/build-android-macos-test.sh` 会运行这些测试。
- 原 Windows 构建脚本 `pwsh -File ./build-android.ps1 -Configuration Release` 因本机没有 PowerShell 不能执行；原有签名密钥也不存在，未生成官方 Release。先在基线源码上用 `/tmp/handycode-build-mac.sh /tmp/handycode-baseline-src /tmp/handycode-baseline-test.apk` 执行等效 aapt2/javac/D8/zipalign/apksigner 测试构建；改造版使用 `./tools/build-android-macos-test.sh`。macOS 辅助脚本是新增的测试构建入口，不改变 Windows Release 签名策略；输出使用 `.local/macos-test-only.keystore`，不可覆盖安装官方版本。
- Android 36 模拟器上，虚构数据验证加密文件、重新读取、失败保留、清除及 Cookie 隔离；总览展示与状态筛选经过 UI 检查。未测试真实用户账号或真实平台数据，也未测试真机身份码、真实会话、过期、完整物流时间轴及 Android 其他版本。没有实现的功能不能由上述测试证明。
- APK 的 manifest 检查：`debuggable=false`、`allowBackup=false`、`usesCleartextTraffic=false`，仅 INTERNET 权限；WebView 调试取决于 debuggable 标志，因此此构建关闭。未新增域名、统计、云服务或 Cookie 导出；静态代码检查不替代真机网络流量核验。
- 参考工程 GPL-3.0 源码未直接复制；HandyCode MIT 与仓库内 AndroidX WebKit Apache-2.0 声明保留。许可证情况是工程检查记录，不构成法律意见。

真机验收：使用独立测试设备/模拟器并确保不覆盖或卸载现有官方安装；登录各官方页面，验证身份码动态刷新、旋转、亮度、手势、主题、分平台退出及 PDD 小号手机号验证；在有真实京东订单时比较原订单页与总览字段及状态；离线/登录失效后检查旧缓存和提示，重新启动核对，清除缓存后确认各平台会话仍在。PDD/淘宝跨平台同步和完整轨迹在实现前无法验收。
